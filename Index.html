Que es una Pagina Web?

Una Página Web es conocida como un documento de tipo electrónico, el cual contiene información digital, con datos visuales y/o sonoros, o una mezcla de ambos, a través de textos, imágenes, gráficos, audio o vídeos y otros tantos materiales dinámicos o estáticos.

Como funciona una Pagina Web?

Un sitio web es una colección de páginas web alojadas en un servidor web y a las que se puede acceder a través de Internet. Un sitio web funciona proporcionando información y servicios a los visitantes mediante una combinación de HTML, CSS , JavaScript y otros lenguajes de programación. El servidor web responde a las peticiones de los navegadores de los visitantes y entrega las páginas web, imágenes, vídeos y otros contenidos solicitados.

Cuales son los tipos de Pagina Web?

  • Páginas web estáticas: Son aquellas que muestran contenido fijo y no se actualizan automáticamente.
  • Páginas web dinámicas: Son aquellas que permiten la interacción con el usuario y la actualización de contenido en tiempo real.

Cual es la diferencia entre una aplicación web y un sitio web?

Un sitio web es un conjunto de páginas web interconectadas que proporcionan información y contenido a los usuarios, mientras que una aplicación web es un software interactivo que se ejecuta en un navegador y permite a los usuarios realizar tareas específicas, como enviar formularios, realizar compras o gestionar datos.
